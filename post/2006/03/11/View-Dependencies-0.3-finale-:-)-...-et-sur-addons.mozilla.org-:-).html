By Florian Quèze on Saturday, March 11 2006, 21:07 - Mozilla - Permalink

View Dependencies 0.3 finale est disponible. Cette version peut-être téléchargée ici ou directement installée à partir du site.

De plus, cette extension est maintenant proposée sur le site addons.mozilla.org.

Voici le commentaire que j'ai reçu lors de la relecture avant la publication sur ce site : « Very nice addition to Firefox. Great work! Thanks, TREV. »
