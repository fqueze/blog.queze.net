View Dependencies 0.3 beta1

By Florian Quèze on Monday, September 19 2005, 16:52 - Mozilla - Permalink

Un nouveau XPI de View Depencencies 0.3 est disponible. Un menu contextuel permettant de copier dans le presse papier ou d'ouvrir les ressources sélectionnées a été ajouté.

View Dependencies 0.3 beta 1

Bugs connus :

  • Les textes ne s'affichent pas toujours dans la bonne langue. (D'autres extensions semblent avoir le même problème. Bug de Firefox 1.0.x )
  • Dans le cas d'une image seule, elle est comptée une fois comme image et une fois comme "html"

Si vous trouvez des bugs, n'hésitez pas à me le faire savoir.

Remarque : Le code de cette version est plus court que celui de la 0.3a1 mais il est toujours très moche !
