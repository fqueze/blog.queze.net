View Dependencies 0.3 alpha1

By Florian Quèze on Sunday, September 18 2005, 23:26 - Mozilla - Permalink

La première version essayable de View Depencencies (=Location=Confid) 0.3 est disponible. Il n'y a pas encore de menu contextuel permettant de copier dans le presse papier ou d'ouvrir les ressources sélectionnées.

View Dependencies 0.3 alpha 1

Bugs connus :

  • Le texte ne s'affiche pas toujours dans la bonne langue (en français sur ma version US de Firefox).
  • Dans le cas d'une image seule, elle est comptée une fois comme image et une fois comme "html"

Si vous trouvez des bugs, n'hésitez pas à me le faire savoir.

Remarque : Le code de cette version est très moche !
