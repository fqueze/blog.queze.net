Compiler Mozilla Firefox et Gaim sur ubuntu

By Florian Quèze on Tuesday, September 5 2006, 13:56

Ça fait déjà quelques fois que je tâtonne pour compiler Firefox sur ubuntu, alors cette fois ci, j'ai noté les noms des paquets que j'ai installés pour que ça fonctionne.

sudo apt-get install gcc g++ libgtk2.0-dev libidl-dev libxt-dev libcurl3-dev

Voila, il n'y a plus qu'à suivre les instructions et ça devrait marcher .

Et pour Gaim :

Le minimum pour que ./configure fonctionne : sudo apt-get install intltool. Le Gaim alors obtenu est sans SSL, donc sans MSN et sans GTalk .

Et si on veut que ça soit vraiment bien... :
sudo apt-get build-dep gaim

Les NOUVEAUX paquets suivants seront installés : build-essential cdbs comerr-dev indent libao-dev libaspell-dev libaudiofile-dev libbonobo2-dev libcamel1.2-dev libebook1.2-dev libedata-book1.2-dev libedataserver1.2-dev libesd0-dev libgconf2-dev libgcrypt11-dev libgnome2-dev libgnomevfs2-dev libgnutls11-dev libgpg-error-dev libgtkspell-dev libhesiod0 libkadm55 libkrb5-dev libltdl3 libltdl3-dev libnspr-dev libopencdk8-dev liborbit2-dev libpopt-dev libstartup-notification0-dev libtasn1-2-dev libxml2-dev libxss-dev libzephyr-dev libzephyr3 tcl8.4-dev tk8.4-dev

Et : sudo apt-get install libgadu-dev libsilc-dev libhowl-dev dbus-1-dev

Wednesday, April 19 2006

View Dependencies 0.3.1

By Florian Quèze on Wednesday, April 19 2006, 15:39

View Dependencies 0.3.1 est disponible depuis quelques jours sur le site de l'extension : http://mozilla.queze.net

Il semblerait que le fichier en téléchargement sur addons.mozilla.org soit corrompu pour certaines personnes. (Peut-être sur un mirroir particulier ?)

Voici la liste des changements dans 0.3.1 :

  • Ajouté : Les éléments de menu « Voir les dépendances » peuvent maintenant être désactivés à partir d'une fenêtre d'options. Ils sont désactivés par défaut.
  • Ajouté : total et subtotaux des éléments.
  • Ajouté : traduction allemande.
  • Ajouté : une icône.
  • Corrigé : « Ouvrir dansun nouvel onglet » fonctionne maintenant si Page Info est ouvert avec All-in-one Sidebar.
  • Corrigé : La taille du fichier html n'est plus comptée deux fois s'il y a une balise object dans attribut data

View Dependencies 0.3.1 Apha 2

By Florian Quèze on Sunday, April 9 2006, 22:11

View Dependencies 0.3.1 est presque prête. Une version de test est téléchargeable ici. Voici la liste des changements :

  • Il est maintenant possible de choisir à l'aide d'une fenêtre d'options si les menus « View Dependencies » du menu Outils et du menu contextuel sont affichés.
  • Correction de bug : maintenant la fonction « Ouvrir dans un nouvel onglet » fonctionne même si Page Info est affiché dans une sidebar (par exemple en utilisant l'extension All-in-one Sidebar)
  • Ajout du total d'éléments de chaque type, serveur, et de la page. Ces totaux sont affichés entre parenthèses :
  • L'extension est maintenant en trois langues : anglais, français et allemand.
