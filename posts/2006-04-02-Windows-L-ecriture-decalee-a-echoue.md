   <p>Pour la deuxième fois que je vais en salle Windows cette année (cette fois ci pour un TP d'Archi), Windows a marqué son enthousiasme à me rencontrer à nouveau par ce message, qui apparaissait à intervalle à peu près régulier&nbsp;:</p>
<p><img src="http://blog.queze.net/pict/ecrituredecalee1.png" alt="Windows n'a pas pu sauvegarder toutes les données pour le fichier [...]. Les données ont été perdues. Cette erreur peut être due à une panne de votre matériel ou de votre conn" /></p>
<p>On peut remarquer sur l'image que le texte du message a été tronqué "par principe" pour faire rentrer le message dans l'info bulle, alors qu'il restait de la place...</p>
<p>Quand il en a eu marre de me mettre des bulles stupides dans la barre des tâches, il a même fini par me cracher un vrai message d'erreur, disant la même chose, mais avec le texte non tronqué&nbsp;:</p>
<p><img src="http://blog.queze.net/pict/ecrituredecalee2.png" alt="Windows n'a pas pu sauvegarder toutes les données pour le fichier [...]. Les données ont été perdues. Cette erreur peut être due à une panne de votre matériel ou de votre connexion réseau. Essayez de sauvegarder ce fichier à un autre emplacement." /></p>
<p>Comment faut-il faire pour sauvegarder dans un autre emplacement puisqu'il nous dit qu'il a perdu les données <img src="/smileys/comprends_pas.png" alt="???" />&nbsp;?</p>
<p>Remarque&nbsp;: je n'étais pas le seul à recevoir ce message.</p>
