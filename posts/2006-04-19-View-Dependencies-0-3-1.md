   <p>View Dependencies 0.3.1 est disponible depuis quelques jours sur le site de l'extension&nbsp;: <a href="http://mozilla.queze.net">http://mozilla.queze.net</a></p>
<p>Il semblerait que le fichier en téléchargement sur addons.mozilla.org soit corrompu pour certaines personnes. (Peut-être sur un mirroir particulier&nbsp;?)</p>
<p>Voici la liste des changements dans 0.3.1&nbsp;:</p>
<ul>
 <li>Ajouté&nbsp;: Les éléments de menu « Voir les dépendances » peuvent maintenant être désactivés à partir d'une fenêtre d'options. Ils sont désactivés par défaut.</li>
 <li>Ajouté&nbsp;: total et subtotaux des éléments.</li>
 <li>Ajouté&nbsp;: traduction allemande.</li>
 <li>Ajouté&nbsp;: une icône.</li>
 <li>Corrigé&nbsp;: « Ouvrir dansun nouvel onglet » fonctionne maintenant si Page Info est ouvert avec All-in-one Sidebar.</li>
 <li>Corrigé&nbsp;: La taille du fichier html n'est plus comptée deux fois s'il y a une balise <code>object</code> dans attribut <code>data</code></li>
</ul>
